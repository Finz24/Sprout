# Use a React GUI with an Effect API and worker

Accepted October 10, 2026, replacing [ADR 0001](0001-modular-application-two-processes.md): the owner selected Option C after comparing Next.js, NestJS and Effect architectures. Use React/Vite/TanStack Router for the GUI and separate Node API and worker processes, with Effect owning backend service composition, typed failures and scoped resources; this gives the media/provider workload an explicit lifecycle at the cost of another process, adapter maintenance and a newly stable Effect major version. Keep PostgreSQL/Drizzle/pgvector, future transactional pg-boss jobs, private originals and shared UI contracts; issue #2 initializes development infrastructure only, while Better Auth, AI SDK, job processing and deployment remain in their dedicated issues.
