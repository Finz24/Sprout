# Issue tracker: GitHub

Issues and specs live at https://github.com/Finz24/Sprout.
Use the gh CLI with an explicit --repo Finz24/Sprout argument.

## Operations

- Publish a spec or ticket by creating a GitHub issue.
- Read the issue body, labels and comments before working on it.
- Check existing issues before creating a duplicate.
- For multiline bodies and comments, use a UTF-8 file and --body-file.
- Apply the labels required by the invoking skill.
- Verify the resulting issue content, labels and URL after publication.

Verify current labels and issue state live rather than treating a local publication note as current tracker state.

## Pull requests as a triage surface

**PRs as a request surface: no.**
